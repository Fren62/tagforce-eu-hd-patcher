# Texture inventory: neutral / specific per language

Generated by `tools/analysis/texture_inventory_languages.py`. **NEUTRAL** = the same hash appears in several languages (de/es included): the PNG is copied as is into the module of the new language (and is normally already in the base pack). **SPECIFIC** = the original differs per language: it must be redone with the words of the language, taking `ui_it`/`ui_fr` as reference.

**How to use it for a new language (es, de).**
- **NEUTRAL** (11 in `ui_it`): same hash in e/f/g/i/s. No work: the PNG already holds for all languages (it is in the base pack, the module does not have to redo it). It is enough to check that the image contains no words of a language.
- **SPECIFIC** (94 in `ui_it`, 85 in `ui_fr`): the original changes per language. For the new language compute the hash of *its* texture (`ui_textures/common.texture`): if it matches the English one or one already covered, it does not need redoing; otherwise it must be redrawn with the words of the language, using the `ui_it` and `ui_fr` PNGs as reference for style and geometry (but **always measure on the original**).
- Known edge cases: `recipe010004` and `duel_draw100014` come out as specific because they do not appear in all 5 languages (check yours); the 6 "local wording" ones (`NUOVO`/`N`/`Fusion`, `pda_pack01`, `icon06`, `mein_menu00`, `trnsmt01`, `d_window00016`, `parts`) are specific: the original of every language already has its HD in the pack.
- The 8 `*.ini` lines that appear as "hash not found" are not textures and were excluded.
